# Runner Caveats

The runner needs a Docker in Docker Daemon to work with docker containers itself. For the connection between the daemon and the runner to work, we need a tls connection and thus a Certificate Authority and a Certificate. 

This is generated by the daemon automatically. Under certain circumstances, the CA can get out of sync and the runner will not be able to connect to the daemon. 

This is solved here by giving the daemon and the runner a persistent volume of 50Mb where the certs will be written. Thus, when the pod dies for some reason the same certificate will still be there.

Considering https://github.com/docker-library/docker/blob/14501013a18c57ec6961114d38753c5152c2cfc0/28/dind/dockerd-entrypoint.sh#L36 the cert has a validity of 825 days. So within this time-frame the server would surely have been updated.
